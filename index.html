WORKING PRINCIPLES

模型可以有創意，
系統不能靠運氣。

01

LLM 不碰最後一哩數字

模型負責解析、提案與解釋；估值、排序、風控和交易條件由確定性程式計算。

02

先嘗試證偽，再談 edge

時間切割、樣本外、成本壓力與多重檢定不是附錄，而是研究引擎的主流程。

03

資料留在該留的地方

能在瀏覽器、本機或唯讀資料層完成的工作，就不多送一份資料到外部服務。

04

失敗要大聲，而且可恢復

關鍵流程採 fail-closed、具名 checkpoint 與可重現測試；缺證據就不算完成。

SECURE BY DEFAULT

公開作品，
不等於公開你的機器。

作品集本身零追蹤、零外部字型、零遠端腳本。需要遠端使用的專案，服務預設只綁 loopback， 再透過有身分驗證的 HTTPS tunnel 或私有網路對外；位址與憑證只從環境設定注入。
